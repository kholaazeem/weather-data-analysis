# ☀️ Historical Weather Data Analysis & Streamlit Dashboard

## 📌 Project Overview
This project involves a comprehensive exploratory data analysis (EDA) of historical weather datasets followed by the development and cloud deployment of an interactive Streamlit web application. The dashboard enables users to analyze weather patterns, temperature distributions, relative humidity, wind speeds, and temporal trends across different regions.

---

## 🚀 Key Findings
1. **Temperature Distributions:** Daily temperatures follow a consistent spread and normal distribution, showing predictable regional averages and seasonal fluctuations.
2. **Humidity & Weather Correlations:** Bivariate scatter analysis and correlation heatmaps demonstrate clear relationships between temperature ranges, humidity levels, and wind behaviors.
3. **Temporal Weather Trends:** Time-series line tracking effectively highlights multi-day weather shifts, capturing seasonal weather anomalies, heat waves, and temperature drops over time.

---

## 🛠️ Project Files in Repository
- **`app.py`**: The complete Python code for the interactive Streamlit dashboard.
- **`weather_data.csv`**: The preprocessed historical weather dataset.
- **`weather_eda.ipynb`**: The Google Colab/Jupyter notebook containing the 8-step EDA, outlier checks, and answered research questions.
- **`requirements.txt`**: The list of Python packages required to run the application.
- **`.gitignore`**: Excludes virtual environment files and caches from GitHub.
